# 🌌 Galactic Astro Portal

A futuristic, high-performance web experience built with **Astro 5**, **Tailwind CSS 4**, and **Three.js**. This project serves as an experimental playground for immersive 3D interfaces and advanced UI interactions.

## 🚀 Key Features

### 💎 Experimental 3D UI Components
- **Voxel & Mesh Worlds**: Dynamic environments using custom voxel and orb geometries.
- **Interplanetary Portals**: Seamless transition effects through 3D spatial gateways.
- **Biomechanical Helix**: A reactive 3D double-helix visualization.
- **Cybernetic Archives**: Interactive 3D data retrieval systems.

### ⚡ Immersive Visual Effects
- **Liquid Metal**: Fluid-simulated surfaces and topological morphing.
- **Holographic Cards**: Multi-layered depth effects for interactive elements.
- **Glitch UI**: Intentional digital artifacts and aesthetic distortion effects.
- **Magnetic Interactions**: Components that react to cursor proximity with realistic weight.

### 🛠️ Tech Stack
- **Framework**: [Astro 5](https://astro.build/) (Content Collections, Server Islands)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) (Next-gen utility-first engine)
- **3D Engine**: [Three.js](https://threejs.org/) (WebGL-based graphics)

## 🧞 Getting Started

All commands are run from the root of the project:

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Build for production |
| `npm run preview` | Preview build locally |
